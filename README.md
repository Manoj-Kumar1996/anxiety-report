# Anxiety Report

A collection of mental-health self-assessment surveys (depression, anxiety, nervous-system quizzes) built with HTML/JS front‑end and PHP backend that emails results.

## Features
- Simple web‑based surveys with clean UI
- PHP script sends completed surveys via SMTP
- Data stored locally (no database)

## Usage
1. Clone the repo  
2. Open `index.html` in a browser  
3. Complete the survey and submit  
4. Check your email for the result
